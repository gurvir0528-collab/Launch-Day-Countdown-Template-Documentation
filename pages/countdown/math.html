Countdown Math

This is the biggest part of our project, and it is important you understand how to set it correctly!

This is the code to set your countdown! Here is how it works!

When you set the countdown, you set it to a certain amount of time from this current momment. Eg. 1hr, 51m from now!

You can edit the days, hours, minutes, and even seconds the countdown is set from now! Heres how..

#of Days

The zero at the beginning of the equation repersents the number of days!

#of Hours

After the days, the 0 in 0/24 operator repersents the number of hours!

#of Minutes

After the hours, adjust the number of minutes by changing the 12 in the 12/1440 operator!

#of seconds

Finally, adjust the number of seconds by changing the 10 in the 10 / (1440 * 60) operator

⚠️ WARNING! ⚠️

To create a global countdown, take the equation OUTSIDE the green flag, set it, and save!

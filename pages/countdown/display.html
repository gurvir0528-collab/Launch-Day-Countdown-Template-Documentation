Display

Moving on, lets discuss and dive into the three displays

1. Number Display

Also called "display" sprite shows the amount of time left

Its a pretty simple script with animation for changing numbers.

⚠️ WARNING! ⚠️

If you change the font, make sure that each number starts with "costume"!

Also make sure that you include the ":" costume!

2. Units Display

called "displays" it shows the units of amount of time left

It switches costume to the var "display2costume#?" which is figured out with the math

⚠️ WARNING! ⚠️

If you change the font, make sure that you keep the same costume names and units in the same order!

Costume 1
Days, Hours, Minutes, Seconds
Costume 2
Hours, Minutes, Seconds
Costume 3
Minutes, Seconds
Costume 4
Seconds

3. Project Display

Also called "display3" sprite shows what we are counting down to

It is not turned on at default, so you will have to use a show block to turn it on if you want it!

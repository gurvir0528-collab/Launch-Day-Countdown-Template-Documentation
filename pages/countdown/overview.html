Overview

Now lets talk about the countdown folder...

Upon opening the countdown folder, you will see four sprites
1. Math
Figures out how much time is left
2. Display
Displays the time on the screen
3. Display2
Displays the units of time
4. Display3
Optional. Displays what is releasing

How these sprites work is using that exact same smooth movment script as before.

We define their positions using OrgX and OrgyY (origin x and y)

⚠️ WARNING! ⚠️

It will take a lot of trial and error to perfect the positions!

Heres a fun section, the items on the scren, otherwise called.

ScreenBackground

Because it also includes the 2 screen backgrounds as well!

This is our setup code, and we spawn 5 clones total

1. Center Screen

(x1)(Orgx:0 OrgY:20)

2. Right/Left

(x2)(Orgx:+/-220 OrgY:20)

3. Items

(x2)(Orgx:+/-220 OrgY:20)

The two screens serve as the actual background for the overlay, and just use a smooth movement script as always.

⚠️ WARNING! ⚠️

Make you that if you change the overlay, you also change the screens and vice versa!

However, the item scripts not only include a smooth movement script, but also a changing script

How it works...

What we do is keep a track of the ghost effect of each clone. Then, if a ghost effect is greater than a certain number, we change the color, until its visible. However,if one clone is switched to the 3rd costume, then both clone will display the 3rd costume

⚠️ WARNING! ⚠️

This system can actually break! IF there is any lag, then for some reason the ghost effect is offset, and stops working. It is a very delicate system!

If anyone can find a better system, please tell me!
